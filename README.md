# DailySpend – Daily Expense Tracking & Budget Management System

## Abstract
DailySpend is a web application developed using React that helps users manage their daily income, expenses, and monthly budgets. Users can manually record transactions, track their spending, and view financial summaries. The application uses browser Local Storage to save data.

## Objectives
- Track daily income and expenses.
- Manage monthly budgets.
- Maintain transaction history.
- View income and expense summaries.
- Store data using Local Storage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- React
- Vite
- Local Storage

## Modules
1. Login and Sign Up
2. Dashboard
3. Add Transaction
4. Transaction History
5. Monthly Budget Management
6. Reports and Financial Summary
7. Profile and Settings

## Features
- User registration and login demonstration.
- Manual income and expense entry.
- Add, edit, and delete transactions.
- Search, filter, and sort transactions.
- Set and monitor monthly budgets.
- View numerical financial summaries.
- Save data in browser Local Storage.
- Responsive user interface.

## Installation and Execution
1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal in your browser.

## Build
To create a production build, run:

`npm run build`

The generated files will be available in the `dist` folder.

## Storage and Security
DailySpend uses browser Local Storage. Data is stored locally in the browser and is not synchronized across devices. The demonstration login is not secure production authentication. Do not use real passwords or sensitive financial information.
